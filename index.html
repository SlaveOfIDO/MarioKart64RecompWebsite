What is MK64 Recompiled?

This is the official website for the MK64 Recomp project, a project to be able to take the original Mario Kart 64 game and recompile it to play on modern platforms.

What are the features?

Fully Intact N64 Effects

All graphical effects that would not scale beyond a 4:3 aspect ratio are preserved, ensuring visual consistency between the original game and the recomp.

Faithful Audio

Music and sounds are perfectly faithful to the original N64 version of the game, with all audio processing intact and no popping or stuttering.

Easy-to-Use Menus

Ingame menus have been moved to a simple settings page that persists between sessions.

High Framerate Support

Play at any framerate you want thanks to functionality provided by RT64! Game objects and terrain, texture scrolling, screen effects, and all HUD elements are all rendered at high framerates.

Widescreen and Ultrawide Support

Any aspect ratio is supported, with all effects modded to work correctly in widescreen.

Mod Support

Install community made mods and texture packs!

Instant Load Times

Transitions are dramatically faster than on original hardware.

Linux and Steam Deck Support

A Linux binary as well as a Flatpak is available for playing on most up-to-date distros, including on the Steam Deck.

Increased Draw Distance

World detail remains visible from farther away, improving visibility across larger spaces.

Full Multiplayer Support

Play with your friends in the traditional offline multiplayer mode.

Setup Guide

Head to the Releases page and scroll down to Assets. That's just a list of downloads, one for each platform. Pick the one that matches your computer below.

The Recomp only works with a US ROM of Mario Kart 64. We do NOT distribute the ROM itself, you need to legally dump your own copy of the ROM before playing the Recomp.

Windows

  1. Download the file with Windows in its name.
  2. Right-click the downloaded zip and choose "Extract All."
  3. Open the extracted folder and run the program inside.
  4. When asked, select your Mario Kart 64 ROM.
  5. Once it opens, check the settings menu to set up your controls and screen options.

Linux

  1. There are two Linux downloads available: a Flatpak and an x64 binary, each in their own zip. Download whichever is relevant to your system. (SteamOS uses Flatpak)
  2. Extract the downloaded zip.
  3. Open a terminal in that folder, or double-click the program if your file manager allows it.
  4. When asked, select your Mario Kart 64 ROM.
  5. Check the settings menu to set up your controls and screen options.

macOS

  1. Download the file with macOS in its name.
  2. Extract the downloaded file.
  3. Open the extracted folder and run the program inside.
  4. When asked, select your Mario Kart 64 ROM.
  5. Check the settings menu to set up your controls and screen options.

Contributing to the recomp!

While we don't implement many changes directly into the recomp itself you can always help make changes there for new integrations such as ray tracing!
Outside of that we highly suggest you contribute to our mod registry so you can help make your mods more discoverable to the community and help others find your work!
